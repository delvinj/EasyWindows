### EasyWindows

Resize and move windows without having to find the edges first.

### Usage

1. Hold down `SHIFT` and ___Left Mouse Button___ to move the window under the cursor.
1. Hold down `SHIFT` and ___Right Mouse Button___ resize the window under the cursor.
1. Use the system tray menu to exit.

### Build

1. `cmake -S . -B build`
1. `cmake --build build --config Release`
